How it works

  1. Agent ID is an on-chain name for an Agentic Wallet (name.ai), issued as a non-transferable NFT by the SPACE ID Agent ID contract on BNB Chain.
  2. AgentTip resolves a name to its owner with tokenId = keccak256(lowercase name without ".ai"), then calls ownerOf(tokenId) — proven against live BSC state.
  3. Your tip goes straight to that owner. The contract takes no fee, holds no funds, and has no owner or admin functions — there is nothing to upgrade or pause.
  4. Every tip emits a Tip event, so the feed above is fully public and verifiable on BscScan.

Tips are one-way payments and are irreversible. AgentTip promises no returns, no yield, and no rewards. Contract source: MIT, open source. Agent ID contract: 0x60B9…022F
